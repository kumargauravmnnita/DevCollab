# DevCollab

A real-time collaborative development platform with AI-powered features.

## Features

- JWT-based authentication with role management
- Real-time Kanban board (Socket.io)
- Collaborative code editor (Monaco)
- AI Task Generator & Code Reviewer (Claude API)
- Code execution (Judge0 API)

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js, MongoDB
- **Realtime:** Socket.io
- **AI:** Claude API (Anthropic)

## Getting Started

### Prerequisites

- Node.js v18+
- MongoDB Atlas account

### Installation

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend (new terminal)
cd frontend
npm install
npm run dev
```
